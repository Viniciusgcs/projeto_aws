Bem-vindo!

Esta página faz parte do projeto prático da disciplina de Desenvolvimento de Sistemas Distribuídos .

Nesta primeira etapa, a aplicação foi implantada em uma máquina virtual AWS EC2 e está sendo executada utilizando Python e Flask.

Ao longo da disciplina, esta aplicação será progressivamente transformada em um sistema distribuído completo.

Arquitetura atual

A aplicação desta primeira aula possui uma arquitetura simples:

Computador do usuário | | HTTP v Internet | v AWS Security Group | v Amazon EC2 | v Linux | v Python | v Flask | v :5000

Recursos utilizados

AWS EC2 Máquina virtual utilizada para executar a aplicação.
Linux Sistema operacional da máquina virtual.
Python Linguagem utilizada para desenvolver a aplicação.
Flask Framework utilizado para implementar o servidor web.
HTTP Protocolo utilizado na comunicação entre cliente e servidor.
Security Group Controle de acesso ao tráfego da instância EC2.

O que será desenvolvido?

A aplicação será evoluída progressivamente durante a disciplina.

  • Computação em nuvem
  • Máquinas virtuais e AWS EC2
  • APIs REST
  • Bancos de dados
  • Docker e containers
  • Redis e sistemas de cache
  • Microsserviços
  • Autenticação JWT e OAuth
  • Comunicação e mensageria
  • Load Balancing
  • Escalabilidade
  • Observabilidade
  • CI/CD

Desafio da Aula 1

Modifique esta página diretamente na sua instância EC2.

Experimente alterar:

  • título da página;
  • informações do professor;
  • descrição da disciplina;
  • arquitetura;
  • lista de tecnologias;
  • estilo visual da página.

Depois de modificar o arquivo, reinicie o Flask e atualize a página no navegador.

Uma pergunta para a próxima aula

Atualmente temos apenas uma instância EC2 executando nossa aplicação.

O que aconteceria se 1.000 usuários acessassem esta aplicação simultaneamente?

Esse problema será o ponto de partida para a evolução da arquitetura ao longo da disciplina.
